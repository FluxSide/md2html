# 项目说明

本文用于说明 `md2html` 的项目背景、目标、功能范围、设计思路和使用边界，方便贡献者或使用者快速建立整体认知。

## 项目背景

在日常文档编写、笔记整理和技术内容发布中，Markdown 已是最常用的写作格式之一。但不同场景下往往还需要将 Markdown 转换为可直接浏览、分发或嵌入的 HTML 文件。

`md2html` 就是为这个场景设计的轻量工具：输入一个 Markdown 文件，输出一个样式化、可直接打开的 HTML 文件，并支持监听模式用于持续编辑。

## 项目目标

- 降低 Markdown 转 HTML 的使用门槛，提供开箱即用的命令行工具
- 输出可读性较好的 HTML，而不是只保留原始 Markdown 结构
- 在简单可用和可维护之间保持克制，避免不必要的复杂性
- 为后续扩展预留合理结构，例如参数解析、输出格式、样式定制等

## 核心功能

- **基础转换**：将单个 Markdown 文件转换为 HTML
- **指定输出路径**：支持通过 `-o` / `--output` 自定义输出文件位置
- **监听模式**：通过 `--watch` 监听输入文件变化并自动重新生成
- **样式化输出**：生成带基础排版样式的 HTML，便于直接阅读
- **参数校验**：对缺失输入、多输入、未知参数等常见误操作给出明确提示

## 适用场景

- 将技术文档、笔记、README 快速生成为可直接预览的 HTML
- 在编辑 Markdown 过程中持续查看转换结果
- 简单静态内容预览，无需完整静态站点生成流程
- 教学或演示 Markdown 到 HTML 的转换结果

## 不适用场景

- 需要复杂站点结构、多页面导航、主题系统的大规模静态站点生成
- 需要与 CMS、数据库、远程构建系统联动的发布流程
- 对 HTML 结构、SEO、无障碍、资源打包有严格工程要求的场景

## 技术选型

- **Node.js + TypeScript**：保证开发体验和可维护性
- **marked**：负责 Markdown 到 HTML 的核心转换
- **chokidar**：负责文件监听，提供稳定的 watch 体验
- **TSX**：用于开发阶段直接运行 TypeScript 入口，降低调试成本
- **TypeScript 编译输出**：最终生成 `dist/` 产物，便于分发和使用

## 目录说明

- `src/cli.ts`：命令行参数解析
- `src/converter.ts`：Markdown 读取、转换和 HTML 写入
- `src/index.ts`：程序入口，串联 CLI、转换和 watch 流程
- `src/test.ts`：内置测试脚本
- `package.json`：项目依赖、脚本和元数据
- `README.md`：主要使用说明
- `docs/getting-started.md`：面向初学者的详细使用指南
- `docs/cheatsheet.md`：常用命令速查
- `docs/project.md`：项目说明文档

## 设计原则

- **简单优先**：优先满足“输入一个文件，得到一个 HTML 文件”的核心需求
- **明确约束**：当前版本只支持单文件转换，避免过度设计
- **体验一致**：命令行行为、报错信息和文档说明保持一致
- **可扩展但不膨胀**：后续若增加新功能，优先评估是否偏离当前目标

## 使用边界说明

- 当前版本主要面向单文件转换，不适合一次性批量处理大量文件
- 输出 HTML 以阅读预览为主，并非生产级网页发布方案
- watch 模式适合本地编辑预览，不建议作为高可靠后台服务使用

## 后续可能方向

- 支持自定义模板或样式文件
- 支持更完整的批量转换模式
- 支持输出目录、资源路径和图片处理策略
- 支持插件式扩展 Markdown 渲染能力
